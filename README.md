# Контрольная работа №4

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

Проект создан на основе контрольной работы №3 (`kr3-responsive-shop`) —
адаптивной версии интернет-магазина книг Харуки Мураками.

Автор: Кузнецова Дарья Александровна, группа ЭФБО-01-25.

## Описание

Интерактивная версия магазина: каталог генерируется из массива товаров
средствами JavaScript, работают поиск, фильтрация и сортировка, реализованы
корзина с сохранением в localStorage, модальное окно товара, валидация формы
заявки и тёмная тема. Фреймворки не используются, только чистый JavaScript.

## JavaScript-файлы

- `data.js` — массив из 10 товаров с единой структурой (id, title, category,
  price, discountPercent, rating, isAvailable, year, pages, imageAlt, images,
  description), справочник категорий и вспомогательные функции: formatPrice,
  getFinalPrice, findProductById, getCategoryTitle, createProductPicture
  (адаптивные обложки: picture + webp/srcset/sizes + lazy loading).
- `catalog.js` — состояние каталога, функции поиска (searchProducts), фильтрации
  (filterProductsByCategory, filterAvailableProducts), сортировки (sortProducts),
  комбинированная подготовка данных (getPreparedProducts) и генерация карточек
  товаров через document.createElement() с выводом текста через textContent.
- `cart.js` — корзина: добавление, удаление, изменение количества, подсчёт
  количества и суммы через reduce, сохранение в localStorage
  (ключ `murakami-cart`), счётчик корзины в шапке и страница корзины.
- `modal.js` — модальное окно товара: создание диалога через DOM API,
  заполнение данными, открытие через showModal() и закрытие через close(),
  возврат фокуса после закрытия.
- `validation.js` — валидация формы заявки: имя (не короче 2 символов), e-mail
  по регулярному выражению, телефон (11 цифр, начинается с 7 или 8), согласие
  на обработку данных. Ошибки выводятся на страницу через textContent с
  атрибутами aria-invalid и aria-describedby, без alert().
- `main.js` — общая инициализация: бургер-меню, переключатель тёмной темы
  (сохранение в localStorage, ключ `murakami-theme`), сообщение об успехе,
  форма обратной связи.

## Массив товаров

10 книг Харуки Мураками трёх категорий: романы (`novels`), рассказы (`stories`),
эссе (`essays`). У каждого товара одинаковая структура свойств, цены записаны
числами. Две книги помечены как отсутствующие — для демонстрации состояния
«Нет в наличии» и отключённой кнопки.

## Реализованный функционал

- генерация карточек каталога через JavaScript;
- поиск по названию книги (событие input);
- фильтрация по категории (событие change);
- фильтрация «только в наличии» (checkbox);
- сортировка: по цене (возрастание и убывание), по названию, по рейтингу;
- пустое состояние каталога и счётчик найденных книг;
- модальное окно с подробной информацией о книге;
- корзина: добавление, удаление, изменение количества, очистка;
- расчёт суммы корзины через reduce с учётом скидок;
- сохранение корзины между визитами в localStorage;
- счётчик товаров корзины в шапке сайта;
- тёмная тема с сохранением выбора в localStorage;
- валидация формы заявки с выводом ошибок на страницу;
- вывод сообщений без alert();
- отладочные сообщения в консоли (console.log, console.table).

## Безопасный вывод данных

Пользовательские данные (строка поиска, данные формы, содержимое localStorage)
нигде не вставляются через innerHTML. Все тексты выводятся через textContent,
элементы создаются через document.createElement() и добавляются через append().

## Самостоятельные доработки

- корзина с добавлением и удалением товаров (cart.html, cart.js);
- расчёт суммы заказа через reduce с учётом скидок;
- сохранение корзины в localStorage с защитой от повреждённых данных;
- тёмная тема с сохранением выбора;
- модальное окно товара с возвратом фокуса;
- расширенная карточка товара: рейтинг, скидка (зачёркнутая цена), статус
  наличия, категория и год;
- заполнение списка книг в форме заявки из массива товаров;
- счётчик найденных книг и пустое состояние каталога;
- поддержка параметра ?product= в ссылке на страницу заявки;
- адаптивные изображения обложек: для каждой книги заранее нарезаны
  варианты 480/640/960 в jpg и webp, браузер выбирает формат и размер
  сам (picture, srcset, sizes, loading="lazy").
